# 🖨️ Bambu Farm Manager (Режим LAN-Only)

Централизованная веб-панель управления и мониторинга фермы 3D-принтеров **Bambu Lab** в изолированном локальном режиме (**LAN-Only Mode**). Система спроектирована для работы без зависимости от облачных серверов Bambu Cloud, обеспечивая полную конфиденциальность данных, стабильность и мгновенный отклик внутри доверенной локальной сети.

---

## 🌟 Основные особенности

- **100% Локальный режим (LAN-Only)**: Прямое взаимодействие с принтерами по протоколам MQTT (TLS порт 8883), FTPS (порт 990) и RTSP видеопотокам. Никакой отправки закрытых моделей или телеметрии во внешнее облако.
- **Поддержка всего модельного ряда Bambu Lab**: X1-Carbon, X1-E, P1S, P1P, A1, A1-Mini и H1-серия.
- **Групповые операции и безопасность**: Преднагрев столов и сопел по профилям пластиков (PLA, PETG, ABS), общее охлаждение, управление подсветкой всех камер и аппаратная кнопка экстренного останова (**E-Stop M112**).
- **Матрица материалов AMS**: Мониторинг катушек филамента, типов пластика, цветовой палитры (HEX), остатка в граммах и процентах, синхронизации RFID, влажности и температуры в боксах.
- **Очередь печати и авто-диспетчер**: Локальная загрузка `.gcode` и `.3mf` (включая Drag-and-Drop), встроенный генератор калибровочных моделей, приоритезация и автоматическое назначение заданий на освободившиеся принтеры фермы.
- **Стена камер RTSP**: Единая сетка видеопотоков со всех принтеров в реальном времени с наложением телеметрии (температуры, слой, имя файла, FPS, пинг).
- **HMS Диагностика и ИИ-доктор (Gemini AI)**: Дешифратор кодов Health Management System Bambu, трекер регламентного ТО (фильтры, трубки PTFE, смазка винтов Z) и интерактивный помощник на базе нейросети Google Gemini.
- **Ручное управление перемещением (Motion Control)**: Интерактивный D-Pad перемещения осей X/Y/Z, парковка (G28), тест экструдера (выдавливание/откат) и точная ШИМ-настройка вентиляторов обдува.
- **Терминал MQTT**: Мониторинг входящих и исходящих JSON-пакетов телеметрии в реальном времени и отправка прямых команд и G-Code.

## 🧭 Навигация и функциональные разделы

### 1. 📊 Панель фермы (Fleet Dashboard)
- Карточки всех принтеров с динамическим статусом (*Печать*, *Простой*, *Нагрев*, *Калибровка*, *Пауза*, *Ошибка*).
- Группировка по стойкам/станциям (напр. *Стойка 01 - Верх*, *Стойка 02*, *Стойка A1*).
- Фильтрация по статусам и локациям.
- Живые графики температур сопла, стола и камеры (библиотека Recharts).
- Переключение скоростных режимов печати «на лету»:
  - 🟢 **Тихий** (Silent, 50%)
  - 🔵 **Стандарт** (Standard, 100%)
  - 🟡 **Спорт** (Sport, 124%)
  - 🔴 **Бешеный** (Ludicrous, 166%)
- Управление питанием, освещением рабочей камеры и логотипа.

### 2. 🧵 Матрица AMS (AMS Material Matrix)
- Сетка слотов катушек для каждого подключенного модуля AMS (до 4 слотов на юнит, поддержка нескольких юнитов).
- Отображение типа полимера (*PLA Basic, PLA Matte, PETG HF, ABS, ASA, TPU 95A, PC, PPA-CF*).
- Цветовой индикатор катушки, остаток в процентах и расчётном весе (в граммах).
- Статус влажности внутри AMS (шкала от 1: Сухой до 5: Влажный).
- Модальное окно тонкой настройки любого слота (смена типа, цвета, производителя и сброс остатка).

### 3. 📑 Очередь печати (Print Queue & Dispatcher)
- Управление списком заданий на печать с установкой приоритета (*Низкий*, *Обычный*, *Высокий*, *Срочный*) и количества требуемых копий.
- Автоматический диспетчер: находит простаивающий принтер с подходящими параметрами и передает файл в работу.
- Локальная загрузка файлов моделей: поддержка выбора файлов через диалоговое окно и перетаскивания (Drag-and-Drop).
- Встроенная генерация калибровочных G-Code тестов:
  - *Калибровочный куб 20×20×20 мм*
  - *Температурная башня PLA/PETG*
  - *Тест втягивания (ретракта)*

### 4. 📹 Стена камер RTSP (Camera Wall)
- Мультиэкран для одновременного визуального контроля всей фермы.
- Наложение HUD-телеметрии в реальном времени: сопло, стол, прогресс, оставшееся время, имя модели.
- Индикатор частоты кадров (FPS) и задержки локального соединения (Ping ms).
- Быстрое включение/выключение светодиодной подсветки прямо из окна камеры.
- Полноэкранный режим просмотра выбранного видеопотока.

### 5. 🔍 Сканер подсети LAN (LAN Subnet Scanner & Credentials)
- Обнаружение принтеров Bambu Lab в локальной подсети (mDNS / SSDP).
- Таблица активных подключений с проверкой портов MQTT TLS (8883) и FTPS (990).
- Безопасное хранение локального 8-значного кода доступа (*LAN Access Code*).
- Ручное добавление принтеров с указанием IP-адреса, серийного номера и стойки.
- Проверка связи (Ping/Handshake) и удаление устройств.

### 6. 🩺 HMS Диагностика и ИИ-доктор (HMS & AI Doctor)
- Дешифратор кодов ошибок Bambu Lab HMS (например, `HMS_0300_1000_0001_0001`, `HMS_0500_0300_0001_0002`) с понятными описаниями и пошаговыми инструкциями по ремонту на русском языке.
- Счётчики регламентного обслуживания оборудования:
  - Общий налёт часов печати (*Print Hours*).
  - Срок службы угольного фильтра камеры (норматив 300 часов).
  - Износ тефлоновых направляющих трубок PTFE (норматив 1000 часов).
  - Интервал смазки ходовых винтов оси Z (норматив 250 часов).
- **Интегрированный ИИ-специалист (Google Gemini 2.5 Flash)**:
  - Консультации по дефектам 3D-печати (вобблинг, эхо, деламинация, сопли).
  - Подбор оптимальных настроек слайсеров OrcaSlicer / Bambu Studio для инженерных материалов.
  - Быстрые шаблоны частых вопросов (*Застревание в AMS, Скоростной профиль PETG, Ошибка термистора*).

### 7. 🕹️ Управление перемещением (Motion Control)
- D-Pad с выбором шага сдвига: 1 мм, 10 мм, 50 мм, 100 мм.
- Перемещение по осям X и Y, подъем и опускание стола по оси Z.
- Парковка отдельных осей (*Home X*, *Home Y*) и всех осей одновременно (*Home All G28*).
- Тест мотора подачи: выдавливание (+10 мм) и откат (-10 мм) филамента.
- Прямое управление скоростью вращения вентиляторов через ШИМ:
  - Вентилятор обдува модели (*Part Cooling Fan*).
  - Вспомогательный боковой вентилятор камеры (*Auxiliary Fan*).
  - Вытяжной вентилятор камеры с угольным фильтром (*Chamber Exhaust*).
- Кнопка обесточивания шаговых двигателей (*M84*).

### 8. 💻 Терминал MQTT (MQTT Packet Stream)
- Поток реальных пакетов от локального брокера принтеров (`device/<SERIAL>/report`).
- Цветовая дифференциация типов сообщений: исходящие команды, входящие ответы, предупреждения и ошибки.
- Консоль ввода для отправки произвольного G-Code или JSON-команд.
- Копирование логов в буфер обмена в один клик.

## 🛠️ Стек технологий

- **Фронтенд**: [React 18](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com/) с поддержкой тёмной темы
- **Иконки**: [Lucide React](https://lucide.dev/)
- **Графики**: [Recharts](https://recharts.org/)
- **Сборщик**: [Vite 5](https://vitejs.dev/)
- **Серверные API / Прокси**: Vite Server Middleware для безопасных запросов к Gemini API
- **ИИ-модель**: Google Gemini (`gemini-2.5-flash`) через официальный SDK `@google/genai`

## 🚀 Установка и запуск

### Требования
- **Node.js**: версии 18+ (рекомендуется Node.js 20+)
- **Пакетный менеджер**: `npm`, `yarn` или `bun`

### 1. Клонирование и переход в проект
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd 3d-printer-control-center
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе примера `.env.example`:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
# API-ключ Google Gemini для работы ИИ-доктора (HMS Doctor)
GEMINI_API_KEY=ваш_ключ_gemini_api
```
*(Если ключ не задан, все функции фермы продолжат работать в автономном режиме, кроме модуля ИИ-диагностики).*

### 4. Запуск в режиме разработки
```bash
npm run dev
```
После запуска откройте в браузере: `http://localhost:3000`

### 5. Сборка для продакшена
```bash
npm run build
```
Статические файлы будут скомпилированы в директорию `dist/`.

## 🔒 Сетевая архитектура и безопасность (LAN Mode)

```text
┌────────────────────────────────────────────────────────┐
│               Локальная сеть (LAN / VLAN)              │
│                                                        │
│   ┌────────────────────────────────────────────────┐   │
│   │     Bambu Farm Manager (React Dashboard)       │   │
│   └──────┬──────────────────┬──────────────────┬───┘   │
│          │                  │                  │       │
│   MQTT TLS (8883)       FTPS (990)        RTSP Stream  │
│   Телеметрия/Команды    Файлы G-Code      Видеокамеры  │
│          │                  │                  │       │
│   ┌──────▼──────────────────▼──────────────────▼───┐   │
│   │             Принтеры Bambu Lab                 │   │
│   │  (X1-Carbon / X1-E / P1S / P1P / A1 / A1 Mini) │   │
│   └────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────┘
```

1. **Изоляция трафика**: Все взаимодействия происходят напрямую между управляющим компьютером/сервером и IP-адресами принтеров.
2. **Шифрование MQTT**: Используется порт 8883 с SSL/TLS рукопожатием и авторизацией по серийному номеру принтера и 8-значному коду доступа LAN.
3. **Безопасность API-ключей**: Ключ Gemini API хранится исключительно на стороне локального сервера и не передаётся в клиентский браузер.
